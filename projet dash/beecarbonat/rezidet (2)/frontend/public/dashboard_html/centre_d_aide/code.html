forum Frequent Queries

How do I calibrate a rogue sensor node? expand_more
To recalibrate a node showing anomalous data, navigate to the ASSETS panel. Locate the sensor ID, select 'Diagnostics', and initiate the 'Zero-State Calibration' protocol. The process requires approx. 45 seconds of system downtime for that specific node.
What is the retention period for analytical logs? expand_more
Standard operational logs are retained in hot storage for 90 days. Aggregated statistical data is kept indefinitely in cold storage. You can request a manual export of historical data via the Security panel if you possess Level 4 clearance.
Can I configure custom threshold alerts? expand_more
Yes. Access Settings > Notification Parameters. You can define multi-variable logic gates (e.g., Temperature > 28°C AND Humidity < 40%) to trigger specific escalation paths across email, SMS, or webhook integrations.
The dashboard is indicating a 'Sync Drift' error. expand_more
A 'Sync Drift' implies the local edge gateway is losing temporal alignment with the central server. Verify the NTP server configuration in the Gateway Settings. If the issue persists, a hard reboot of the physical gateway module is recommended.
